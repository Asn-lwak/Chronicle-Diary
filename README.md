# Chronicle — Fully Offline, Responsive Edition

Open `index.html` to use Chronicle. Keep the `css`, `js`, `assets`, and `docs` folders together with it.

This edition is intended to work without online fonts, external styling libraries, or server-based diary synchronization. Diary data stays in the browser storage for the browser/profile in which it was created. Use the app's backup/export and import/restore tools to transfer data manually between devices.

## Mobile controls update

The editor toolbar now scrolls or wraps on narrow screens so the Camera, Gallery, Sketch, and recording controls have room and are less likely to overlap. Camera and microphone availability still depends on browser permissions and platform rules.

See `docs/MOBILE-TESTING.md` and `docs/OFFLINE-AND-DEVICE-NOTES.md` before relying on the app for important data. This update has not been fully tested on every physical device/browser.
